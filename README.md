# design-assets

Images referenced from GitHub Discussions and issues (design mockups, screenshots). Never merged into master; each directory is one discussion.

- `tab-strip-directions/`: mockups for the header + session tab strip redesign discussion.
- `media-kit-2026-10/`: lossless screenshots of a live Codeman 1.40.0 (agent fleet, Tiles view, local DeepSeek, orchestration, approvals inbox, phone) plus the Tiles toggle clip, for articles, posts and the website.
- `release-1.41/`: the Codeman 1.41.0 release clip, six live agents in the tile grid powering on and off with the CRT tile animation (800 px GIF), used in the release notes and the announcement.
