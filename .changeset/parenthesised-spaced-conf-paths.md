A parenthesised file path whose name contains a space (`(/mnt/data/Kobo/Kobo eReader.conf)`, including one hard-wrapped between the words) is linked as that whole file. `.conf` is a link extension, the same text the attachment routes already serve. The space the wrap consumed stays in the path, and the clickable cells stay on the rows that hold the name.
